# NOT YET GONE

A first-person scrollytelling digital narrative about koala habitat loss.

**Course:** COMM2595 Digital Narrative Theory and Practice  
**Student:** Suzhe Wen (s4173810)

## Run locally
Open `index.html` using Live Server in VS Code, or serve the folder with any static web server.

## Technology
- HTML5
- CSS3
- JavaScript
- GSAP + ScrollTrigger (loaded from CDN)

## Experience structure
HOME -> GAPS -> GROUND -> FIRE -> STILL HERE -> SOURCES

The site uses scrolling as a narrative mechanism: habitat fragmentation, ground exposure, fire/smoke and recovery are communicated through controlled visual changes. The final build includes keyboard-readable content order, a skip link, reduced-motion control and official research links.
